# Cinematic Camera v0.1.2

JPEG 保存の処理を高速化しました。撮影・現像の結果と画質は変わりません。元の DNG は変更しません。

## 主な変更
- 保存時の GPU 処理を、画像を帯状に分けて転送する方式に変更しました。
- 原本の読み込みを GPU 側で変換する方式に変更し、CPU 側の変換処理をなくしました。

## 効果
- Pixel 9a の計測版で同じ DNG・設定を比較した保存時間の中央値は、12MP は約6.6秒から約5.6秒、24MP は約10.7秒から約9.4秒になりました。各サイズ6回の中央値です。時間は画像や端末の状態によって変わります。
- 変更前後の最終画像が全画素で一致することを検証環境で確認済みです。取り消し・再試行などの保存の安全動作も確認しました。

## 既知の制約
- 従来どおり、アプリを離れると画面を開いたままの場合より保存に時間がかかることがあります。

保存工程の時間などの診断記録は端末内にのみ保持し、アプリから外部には送信しません。
