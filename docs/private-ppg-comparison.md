# 実写 AHD / PPG 比較版（準備中）

## 現在地
比較専用の別 ID Debug 版を準備中。実機投入・公開・PPG 採用は未承認。
ビルド、合成入力の試験、独立レビューを完了してから、本人へ所要時間と操作を提示する。

## 安全境界
- アプリ ID: dev.cinematic.p0.previewcompare。通常の dev.cinematic.p0 を上書きしない。
- ephemeral_debug 署名のみ。製品署名モードは禁止、Release variant は作らない。
- 明示の -PcinematicPreviewCompare=true だけで画面/JNIを含める。
- 既存の LibRaw を再利用。PPG は比較版の専用入口のみ、通常のプレビューと保存 AHD は変更しない。
- 本人が Files から選んだ 1 枚のみ read-only で読み取る。永続 URI 許可は取得しない。
- 一時コピーはこの別アプリの内部 cache のみ。比較完了・取消時に閉じて削除。
- 解放失敗後は同じプロセスでの再試行を禁止。再起動後、前プロセスの固定名残件のみ整理する。
- 写真名/URI/画像をログ、リポジトリ、共有領域、ネットワークへ出さない。画面キャプチャ/recents も FLAG_SECURE で抑止。
- JPEG の書き出し機能はない。製品の編集設定/台帳/既存 JPEG に触れない。
- OS に終了された場合は一時 cache が残り得る。再起動時の比較開始前に整理し、最終的には比較アプリのアンインストールで削除する。

## 比較条件
原寸 AHD / 原寸 PPG を順番に展開し、既存 BOX 縮小と GPU パイプラインで1024px以下にする。
強さ0.5、暖かさ0、手動露出0/-1/-2EV。製品に保存済みの調整値は使用しない。
AHD/PPG切替で拡大位置を保持する。結果はメモリだけに保持し、背景化したら破棄する。
原本が選択後に変わった場合は結果を破棄する。

## 本人向け手順案（未開始）
接続時に比較用別アプリの導入を確認し、端末内のSIGMAステージDNGを本人が選択する。
1枚ずつAHD/PPGを切り替え、照明の縁→顔/髪→衣装の細かい模様→暗部を確認する。
必要なら露出を-1/-2にして同じ写真を選び直す。
報告は「差なし／気になる場所・色や縁の違い」の文章だけでよい。写真送付は不要。
3枚で約10〜15分を仮置きするが、起動/処理時間はAVD試験後に更新する。
未採用なので普段の撮影・編集・保存は製品版を使う。
