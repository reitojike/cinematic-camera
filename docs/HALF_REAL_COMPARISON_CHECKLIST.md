# 本人用 FULL / half 比較チェックリスト

実施は最終実機確認後の別回が基本です。比較版の導入・操作は別途承認後。
準備中の手順であり、実写/実機の合格やhalf採用はまだ決まっていません。

- [ ] 承認した比較版を開く。既知の端末内DNGを12MP/24MP各1枚用意する。
- [ ] 1枚目を品質画面で選び、同じ位置・倍率でFULL/HALFを切り替える（強さ0.5・0 EV）。
- [ ] 細線・模様・暗部・色を「問題なし/気になる差/判断不能」で控える。
- [ ] 白飛びで判別不能な場合だけ−1/−2 EVを追加する。
- [ ] 「速度を別に比較」でローカルDNGの確認をチェックし、同じ写真を選ぶ。
- [ ] 4回の自動計測を前景で待つ。「完了・一時データ解放済み」と4標本・thermalを確認する。
- [ ] 数値と判定だけ控え、「取消・閉じる」で戻る。2枚目も同様に行う。
- [ ] 観点が足りなければ3枚目を相談し、halfの採否を判断する。

失敗・無応答・解放未確認なら中止。写真・URI・ファイル名・未加工ログを送らない。
本人操作は暫定10〜15分、待ち時間込みは未確定。
