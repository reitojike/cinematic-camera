## 提案

**案 A `#FF6B6B` を推奨**します。現行のサーモン色からオレンジ寄りの印象を減らし、Amber の警告線と赤い失敗線を区別しやすくする狙いです。B は少し柔らかいローズ寄りの代案です。最終判断は実際の画面内で見た好みに合わせます。

|項目|現行|案 A|案 B|
|---|---|---|---|
|Failed|`#EF8A74`|`#FF6B6B`|`#F47983`|
|Ink `#0A0B0C` に対するコントラスト比|8.03|7.10|7.42|
|Panel `#111315` に対するコントラスト比|7.59|6.71|7.01|

比率は sRGB を線形化した相対輝度から `(明るい側+0.05)/(暗い側+0.05)` で計算しました。候補は現行より若干暗くなるため、色の区別と文字の明るさを併せて判断してください。この計算だけでアクセシビリティ基準の全要件や色覚差への十分性を保証しません。

WARNING は `#E6A35C`、録画は `#E5483B` / RecordingText `#FF7A6E` のままです。録画と失敗はともに赤系なので、色だけに意味を負わせず、REC・経過時間・操作と失敗文言を維持します。

## 見る箇所

1. 権限なし：問題カードの見出し「カメラを使えません」の読みやすさ。
2. 高温・通常：WARNING 線は黄色のまま。重症度 SEVERE チップは元から FAILURE トーンなので、候補ではチップだけ赤が変わります。
3. 高温・拒否直後：02の警告線と03の失敗線を見分けられるか。本文・幅・位置は同じです。
4. 録画中：既存の赤と並べて、失敗色が紛らわしくないか。録画画面自体は全画素不変です。
