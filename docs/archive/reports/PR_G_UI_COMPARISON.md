# PR-G 変更前・変更後の主要画面比較

左が変更前、右が変更後です。画像を開くと拡大できます。通常画面15組と、500dp・文字1.8倍の重点確認5組です。

- 比較元: `b195c39d`、変更後の製品・試験: `129c615f`（本資料追加前）。
- 合成画像のみ。写真・URI・端末識別情報は含みません。
- ATD上のソフトウェアView描画。GPU描画・handoff・Pixel実機の受け入れ結果ではありません。撮影は共通部品の合成表示、初期案内はcaption部品単体です。現像の画像部分は試験用bitmap経路のため、GPU製品画面とは補助captionが異なります。
- 500dpの下部画像は既存の縦スクロールを使って保存行を表示しています。
- 見た目は本人承認前のため、マージしません。

## 検証状況

- 変更前後それぞれ64場面・120画像を取得。全120組の詳細比較は補助PDFに収録。
- 変更後の全4条件（360×760dp、360×500dp、各文字1.0倍/1.8倍）で、全保存状態の有効/無効・状態説明・保存領域・3パラメータの同一高さassertが成功。
- 既存Android回帰は変更前後とも7件中6件成功。残り1件はfull-accessかつ空一覧で「アクセスを許可」が存在する既存実装と、存在しないとする期待値の不一致。今回の色変更による退行ではなく、別件 [#462](https://github.com/reitojike/cinematic-camera/issues/462) として未解決です。
- 本資料の目視確認と自動試験は、実機手動回帰の代替ではありません。

### 最終候補の確認値

- 129c615f（#458取込み済み）：lintエラー0、JVM 1434件・失敗/エラー0・skip12、app/test APK build成功。
- 56保存caseのタッチ領域：最小幅76.00dp、高さ82.33〜95.33dp。最小76dpと既存96dp行内の両条件を満たす。
- 統合後のDevelopViewAndroidTestは1件成功。上記#462の不整合は別途未解決。
- 限定手動確認：500dp・文字1.8倍でADB tapによる強さ→色温度→明るさ→強さの内部選択、上下swipe後の保存行到達、情報ダイアログの開閉と全文を確認。ダイアログはactive-windowのアクセシビリティツリーで確認し、別windowの見た目合格とは扱わない。
- 外部の保存/取消/公開callbackは合成fixture内で無作用。実機・GPU・実際の保存/取消の手動受入へ読み替えない。
