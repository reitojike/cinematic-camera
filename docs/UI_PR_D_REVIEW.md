| 変更前 | 変更後 |

| 表示が要求に未到達でも通常色 | 上記キャプション + 更新中、WARNING |

| 再保存確認の危険操作が閉じる操作と近接 | 危険操作直前を広く空ける（順序・非強調は維持） |
