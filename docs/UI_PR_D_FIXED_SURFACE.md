# PR-D: 固定 Surface の確認

本人指定の案を1回実証した記録。閉じた状態から調整パネルを3往復し、SurfaceViewは1080×1472で固定、GL描画範囲のみ上寄せに縮める。写真owner・decode・保存状態・メモリ判定は変更しない。NORMALの同じパラメーターを再利用し、FULL_RECOMPUTEへは移行しない。

## 動的確認

- AOSP read-only cold boot、合成1024×768 DNG。Pixelではない。
- 13,458msの録画、108記録フレームを全抽出。中央720点の黒フレーム0件。
- 中央列の画像の上下端は108件すべて、閉607–1416または開448–1257の2種類だけ。代表画像目視でも位置・縮尺に異常なし。
- 開閉中のSurface resizeとEGL window再作成0件。同一renderer/Surfaceを維持。
- 長押し/アクセシビリティは可視画像領域のCompose Boxに残す。現製品に顔枠やタップ位置の画像座標変換はない。
- 余分な静止画像やテクスチャを保持しない。開いている間も閉状態のSurface bufferサイズを維持するため、その部分の縮小はしないが、保存時には既存どおりGPU sessionを外す。

固定寸法は同session/幅で観測した最大値。通常のGPU再生成は編集sessionを閉じる。ウィンドウ幅変更・回転によるSurface寸法変更まで禁止するものではなく、今回の録画は固定幅でのパネル開閉の検証。

録画の全フレームは全エンコードサンプルを意味し、録画器が落とした物理表示フレームまで保証しない。

## 不採用の案

- EGL window再利用だけ: 位置・縮尺ずれで不採用。
- Callback2だけ: 黒フレーム1件が残り不採用。
- 有界resize handshake: 本人の最新指示でビルドまでで停止、実走・採用なし。

## 通常検証

最終 CI・GPU90/帯・UI/保存安全試験の結果は PR に記録する。未完を合格扱いしない。

## 再描画と光学効果の確認

旧サイズ変更経路も resizeSurface → latest.invalidate → renderFrame → renderPreview → pipeline.render で Glow 合成・Mist・finish を再実行する。固定案だけで追加される工程ではない。本人の追加説明に従い、これを不採用理由とはしない。開閉の動的証拠は上記録画であり、操作受付から描画完了までの専用時間計測は未実施。

表示高さ・viewportY は最終 present にだけ渡し、処理テクスチャ寸法・request.params・光学定数は不変。各処理パスは自身の出力寸法に viewport を設定し直す。Mist 自動強度も同じ全処理画像から計算し、表示領域によって Glow / Mist の半径や効き方を変えない。独立コードレビューでも確認済み。
