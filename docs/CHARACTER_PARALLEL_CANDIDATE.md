# Character row candidate (unverified integration)

Base: `main` `f250e3155174f56a512b1e9fac34424fb8c18b22`. This local candidate is not a released or measured build. It reuses the earlier `e6765c0` experiment and the bounded `OriginalRasterWorkspace.mapParallelRows` owner/cleanup contract merged in #180.

The previous synthetic 24MP A/B used a two-core API 37 AVD, the same DNG and strength 0.5, with A1/B1/B2/A2 in that order. Final JPEG SHA matched in all four runs. Character stage was 70.781/62.596 seconds serial and 39.484/42.252 seconds with two workers. Whole-export timing moved substantially with host/warmup state; the reverse-order pair was 434.187 seconds serial versus 422.245 seconds candidate. This does not establish a stable whole-export improvement, and it is not Pixel evidence. Source record: `D:\Users\jack0\AppData\Local\Temp\cinematic-character-ab\HANDOFF.md`.

The candidate parallelizes only the Character row step when `faces === OriginalMask.NONE`. The current original-size save explicitly selects two workers and supplies that built-in zero mask; the `OriginalStageClear24` reference default stays serial. A caller-supplied face mask remains on the serial path because its `row` callback may be stateful, including on a face-cut second pass. The vignette loop, vibrance and skin cap keep their existing order and formulas; zero-mask skin cap still runs its Lab conversions. Each worker owns its borrowed-row copy and mask row. There are two workers and at most four in-flight rows, so additional arrays scale with row width rather than 24MP frame area. Cancellation/interrupt checks surround each row stage and occur inside the vignette loop; the existing vibrance and skin-cap calls each process one row before the next check. #180 retains unfinished worker ownership, blocks admission and permits retryable cleanup after timeout/interruption.

Added small JVM tests compare float raw bits for the same zero mask at serial/two-worker settings and keep a custom mask callback on the caller. They also inject cancellation and an exception after Character begins and assert owner cleanup. **These tests have not been executed yet** because another task owns the host's heavy build/AVD window. No new AVD or Pixel measurement, full 24MP completion, or real-photo quality judgment has been made for this integration. Do not open or merge a product PR until targeted and full checks pass and the integration receives independent review.

Glow is deferred: its bloom/halation fields precede a light row composite, and the diffusion field is computed from that composite before a second row composite. Those phases cannot be treated as one independent row transform without changing their dependencies. A later candidate could parallelize either row-composite phase separately, with private field-row buffers and the same owner contract, after Character is validated.
