## 今回と前回の画像は何か

前回も、約3.15MPの原寸展開画像をそのまま見せたものではなく、**原寸でデモザイク→既存の1024px上限・画素上限への縮小→製品GPUプレビュー**でした（1023×768、縦768×1023）。原寸のままなのは別リンクの保存AHD JPEGだけです。

今回は入力を12MP/24MP相当に増やし、同じ `GpuPreviewInputSize.fit` → `OriginalFields.reduce` → `DefaultStageClearGpu` の表示出力を採っています。画面の装飾を合成したmockではなく、実際のプレビュー画素です。保存処理・FULL既定・採用基準は変更していません。

## 分かったこと

- **02/05：縮小してもPPGの緑寄りの差は残ります。** 前回MAE約11.7から、12MPで約9.59、24MPで約8.94〜8.98へ下がりましたが、全体にも色の偏りが見えます。「縮小すれば偽色が消える」とは言えません。
- **03：照明の縁は、この合成条件ではAHDに非常に近い結果**です。平均差は小さい一方、最大差は12MPで33/255、24MPで18/255の局所差があります。
- 格子は元画像上3px/11pxのまま。前回と縮小率が違うため、差の低下はこの縮小条件での結果であり、デモザイク自体の改善ではありません。AHD側にも人工条件由来の模様があります。
- 全体として「差が十分小さい」とこちらで採用判定はしません。本人の目視判断待ちです。
