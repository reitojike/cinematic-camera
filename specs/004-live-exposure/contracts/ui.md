# UI contract
ISO/SSは合法候補を選ぶと要求、適用/取消ボタンなし。MFの適用/取消は維持。ISO/SSを閉じても送信済設定は取り消さない。
送信/queue中はISO/SSの次候補だけ入力可能、撮影と他設定は禁止。要求pairは最新値、API受付は送信順の履歴、実測は独立更新。最新希望を古いACKで置換しない。
AUTOは待機を破棄し旧操作tokenを無効化して新snapshotを送る。WB/MF等を保持する。失敗/期限後はUnknownと理由、AUTO/再接続の導線を残す。
長秒はs、短秒は1/n s。合法候補なし/実測初期pairなし/非対応は理由を表示。状態を文字列parseして制御しない。
