# カメラロールの現行仕様

## 一覧とアクセス

- 現在の最低対応は [Android 13 / API 33](../diagnostics/spec.md)。MediaStore が返すアクセス可能な他アプリを含む画像・RAW・動画を新しい順に表示し、pending / trash は除外する。
- 種類は「すべて / 画像 / RAW / 動画」。画像フィルタはRAWを除き、RAWはDNGと他のRAW候補を含む。種類・フォルダの条件は全アクセス範囲への問い合わせに適用し、読み込み済みページだけを絞り込まない。volume と相対フォルダを区別する。
- 初期・追加ページは既定60件。続きがある場合は「さらに読み込む」を表示し、画像・動画を共通の順序とページ境界で扱う。更新・復帰時は先頭から読み直す。更新中のライブラリを固定snapshotとはみなさない。
- 画像・動画別の許可、部分許可、再選択、拒否・失効を扱う。アクセスは明示操作で標準権限要求へ進み、結果と復帰時にOSの最新grantを再確認する。grantや一覧のURIを永続的な読み取り権利として保存しない。
- API33は READ_MEDIA_IMAGES / READ_MEDIA_VIDEO、API34以降は READ_MEDIA_VISUAL_USER_SELECTED も扱う。全面・部分・画像のみ・動画のみ・混合・未許可を区別し、選択許可ではOSが読取りを許可した項目だけを表示する。
- 写真・動画とも全面許可ならアクセス帯は省略する。それ以外ではアクセス状態の説明と許可・再選択・設定への入口を設け、部分アクセスは破線アンバー枠とアンバー文字で示す。未許可でも現在読めるアプリ所有の撮影物は表示できるため、未許可と空一覧を同一視しない。

## 表示と操作

- 見出しは最小52dp、更新ボタンは最小44dp四方、絞り込み帯は最小48dp、読込・開く処理の進捗線は2dpのアンバー。フッターは最小64dpで、文字拡大時は必要な高さを確保する。
- 3列・2dp間隔で、MediaStoreの追加日時を端末のローカル日付でまとめる。取得不能・不正・0以下の日時は「日付不明」とし、架空の日付を付けない。日付別件数とフッターの種類別件数は読み込み済み範囲であり、全ライブラリの総数ではない。
- DNG / 他RAW / 動画を左下のタグで区別し、取得できる場合だけ動画時間を表示する。読み込み済み項目のうち追加日時が有効な最新1枚を緑の内枠で示す。画像名をアクセシビリティ情報に保持する。
- 同じ検索条件・同じアクセス世代の更新中と追加読込中は既存タイルを保持する。種類・フォルダ・権限の変更、背景化では古い集合を現在の結果として表示しない。読込中は空状態を確定表示しない。
- 読み込み完了後の空一覧には中央の説明と「アクセスを許可」「Filesから選ぶ」を設ける。フィルタで空になった場合に権限なしと断定しない。権限・Files・更新・選択の有効条件は上位画面が持ち、無効時には処理を呼ばず、有効時の1操作を1回のcallbackへ渡す。
- サムネイルの読み込み中・失敗は共通パネル色・文字色・書体の代替表示とする。待機と「プレビューなし」を区別する。
- 通常縦画面、狭い画面、横持ち、長いフォルダ名、大きい文字でも、必要なスクロールで操作・フッターへ到達できる。全操作が初期画面へ同時に収まる保証ではない。
- MANUAL_TRIAL / PRIVATE_TRIAL は一覧の試験品質注記と展開説明を保ち、現像側の詳細注意も消さない。手動保存・共有へ保存しない経路、原本不変、暫定色・顔保護なしなどの制限を完成品質と取り違えない。

## サムネイルの向き


- JPEG・動画・外部RAWを含め、縮小像の取得は標準 `ContentResolver.loadThumbnail` を維持する。DNG原本のRAW展開や追加の画像デコードは行わない。
- DNGはAndroidX ExifInterfaceでOrientationと報告寸法だけを読み、90/270度・元寸法も返却Bitmapも明確な横長・縦横比が縮小端数2px以内で一致する場合だけ縮小Bitmapを回転する。縦横差4px以下は曖昧として扱う。
- 回転済みの縦長Bitmapと、元寸法が縦長の場合は追加回転しない。180度・反転・正方形・寸法不明・縦横比不一致のcropは対象外。providerの任意cropや同じ比率への変形を一般的に識別できる保証はなく、この限定範囲外の向き改善は保証しない。
- メタデータ読込は64MiB以下の原本を読取り専用で開く。メタデータ読込失敗・対象外ではprovider画像を維持する。追加Bitmapは既存縮小像の回転結果1枚だけで、原寸画像やRAW配列を作らない。
- 可視セルのみ・取得最大2件を維持する。取消はメタデータ読込の境界と回転前後に確認し、遅延した結果は返さない。FDと未返却Bitmapを解放する。原本への書込みや恒久コピーは行わない。

## 選択と安全性

- 写真・動画・他RAWは同じURIの公開状態・種別・読取可否を開く直前に再確認し、標準ビューアへ読み取りURI権限だけで渡す。削除・失効・種別変更・ビューア不在は失敗として示す。独自の動画再生や編集は行わない。
- DNGは全バイト照合を含む既存原本検証を通して編集へ進む。MediaStoreでは内部ストレージの公開済み原本に限定し、他アプリ由来を自アプリ所有として扱わない。RAW一覧に出ることは現像対応の保証ではない。
- Filesは標準選択を使い、現行の端末内DNG対応範囲に限定する。外部SD・クラウド・「最近使った項目」からの取り込みや他RAWの現像を保証しない。詳細は[原本・保存](../storage/spec.md)と[編集・プレビュー](../develop/spec.md)を参照する。
- 背景化・退出で一覧取得・サムネイル・外部ビューア準備を取り消す。成功・失敗とも遅い旧結果を新しい一覧に採用せず、退出後に遅れてビューアを開かない。完全URIを識別子とし、collection / volume間の同じ数値IDを混同しない。
- ロールの閲覧・選択は原本への書き込み・移動・削除・恒久コピーを行わない。私有試験JPEGを公開一覧へ混入させない。全ストレージ管理、音声ライブラリ・位置情報アクセス、MediaStore未登録ファイルやクラウド全体の探索を要求しない。

## 外部DNGの取り込み（#101 partial・接続案）

- 直接開くFiles導線と別に「外部DNGを取り込む」を設け、標準SAFで選んだ64MiB以下のローカルDNGを共有領域へコピーする。コピー前に編集へ渡さず、全byte/close/公開後再読取を確認した共有URIだけ既存編集へ渡す。
- 取り込みパネルは完成原本と中断記録を再発見し、明示再開/取消を受け付ける。背景化した古い結果では編集へ遷移しない。現像非対応でもコピー済み原本は保持し、既存理由表示を使う。
- この明示取り込みだけ共有原本1つを作る。通常の一覧閲覧/直接選択の非複製契約は維持する。実機・実写真・SD抜去は未確認。詳細は[取り込み契約](../../docs/DNG_IMPORT_CONTRACT.md)。
- picker復帰直後は現在世代の最初のリソース観測通知まで選択を保留し、既存入力準備の10秒以内に観測できなければ選び直しを示す。観測後は既存受付を一度だけ行い、低メモリ等のblocker解消を待つ自動再試行はしない。受付前の取消・閉じるは選択を同期無効化し、待機開始後の背景化は観測世代の変化でも旧選択を破棄する。同URIの古い選択も後から開始しない。
