# カメラロールの現行仕様

## 一覧とアクセス

- MediaStore が返すアクセス可能な画像・RAW・動画を新しい順に表示し、追加読み込みに対応する。pending / trash は除外する。
- フォルダと種類でライブラリを絞り込む。読み込み済みのページだけを全件とみなさず、volume と相対フォルダを区別する。
- 画像・動画別の許可、部分許可、再選択、失効を扱う。復帰時にはアクセスを再確認し、失効した一覧・サムネイルを使い回さない。
- 写真・動画とも全面許可ならアクセス帯を表示しない。部分アクセスは破線アンバー枠とアンバー文字で示す。混合状態・未許可・非対応はそれぞれ事実に沿って説明する。
- 読み込み完了後の空一覧には中央の説明と「アクセスを許可」「Filesから選ぶ」を設け、既存の有効条件を維持する。フィルタで空になった場合に権限なしと断定しない。
- 3列・2dp間隔の一覧、種類・日付等の情報と直近の表示を維持する。サムネイルの読み込み中・失敗は共通の色による代替表示にする。

## 選択と安全性

- 写真・動画・他RAWの閲覧は、公開状態・種別・読み取り可否を確認し、読み取りURI権限で標準ビューアへ渡す。
- DNGは既存の原本検証を通して編集へ進む。他アプリ由来を自アプリ所有として扱わない。RAW一覧に出ることは現像対応の保証ではない。
- 背景化・退出時に一覧取得・サムネイル・外部ビューア準備を取り消し、退出後に遅い結果で画面を開かない。
- 原本への書き込み・移動・削除、全ストレージ管理、クラウド全体の探索は行わない。
