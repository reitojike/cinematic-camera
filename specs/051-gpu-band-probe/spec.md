# GPU帯合成の比較基盤
Status: Draft
Issue: #212

## 利用シナリオ・受入条件
合成RAW相当の線形RGBを既存R7・Look・表示変換へ通し、CPUとGPU候補を同じ入力で比較する。製品に接続せず、テスト入口から明示起動する。
プレビューは8bit最大2段以内、差のある画素割合と暗部の縞を記録し、比較ページの本人目視が必要。保存は現像全体最大1段以内。未達ならCPU保存を維持する。既存CPU goldenは変更しない。

## 対象外・停止条件
個人写真、実機、Release、製品採用、既存工程の変更を含まない。GPU候補は見た目差のため自動マージしない。許容差超過で原因・数値を報告して停止する。保存全体を通していない結果を原寸合格と呼ばない。

## Requirements
- FR-001: 製品未接続・testから明示起動、既存工程ファイルを変更しない。
- FR-002: 全画像CPUぼかしの境界を維持し、GPU合成入出力だけ有界帯とする。
- FR-003: GPUの8bit最大差・差画素率・暗部縞の指標と比較画像を記録する。
- FR-004: 取消・失敗では出力を公開せずGL資源を回収する。

## Success Criteria
- SC-001: 対応する合成入力の全Lookでpreview最大差2以内、帯高さによる差なし。本人の比較ページ目視は別の未完条件。
- SC-002: 原寸保存の全経路を通していなければ保存最大差1の合格を主張しない。
- SC-003: エミュレーターの時間は参考。GPU driverを含む真のpeakは未測定と明記する。
