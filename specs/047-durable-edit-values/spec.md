# 写真別の手動現像設定の保持

## User Scenarios & Testing
### US1 - 確定した調整を再利用する (P1)
Pixel 9a の12MP DNGを手動現像し、調整を閉じた後、一覧へ戻る・アプリを終了する操作を経ても、同じ原本で強度・相対色温度・明るさを再利用できる。
- 3値を変更して表示を確認し「閉じる」を押すと、保存を確認してから調整を閉じる。
- 同じ原本を選び直すと3値を復元し、その値でプレビューと手動保存を行う。
- 取消、未提出ドラッグ、別の写真には確定値を流用しない。
### US2 - 原本や保存状態が不確かなとき停止する (P1)
- 原本の参照・内容・アクセス契約が一致しない記録を復元しない。
- 未知の処理版、破損、設定保存・照合失敗を成功扱いにしない。
- Androidの再生成時に保持された画面内の提出済み値を、古い永続値で上書きしない。

## Requirements
- FR-001: 保存対象は調整を閉じる時点で表示済みの確定3値と原本識別、処理定義だけ。画像・DNG・権限を複製しない。
- FR-002: 復元前に従来どおり原本の読み取り権限と内容を確認する。
- FR-003: 保存は原子的置換と読み戻し照合を行う。完了前に保持成功と表示しない。
- FR-004: 保存要求中の二重操作を抑止し、背景移動や画面終了が起きても確定した要求の小さい書込を完了させる。古い応答で新しい画面を変更しない。
- FR-005: JPEG保存owner・世代・公開判断は変更しない。編集設定の保持はJPEG保存完了ではない。
- FR-006: 原本参照・内容・アクセス契約と現行の手動現像recipeが厳密に一致するときだけ復元する。

## Success Criteria
- SC-001: 新しい保存オブジェクトと画面で同じ3値を取り出せる。
- SC-002: 異なる原本、破損、未知版、不正値、短読、保存失敗は誤復元・誤成功0件。
- SC-003: 取消・再生成・別写真・古い応答の回帰を自動試験する。Pixel実機受入は別に残す。

## Assumptions / Scope
#81の残件を対象とする。原本は共有領域に読み取り可能な状態で残り、Files経由は必要に応じ再選択する。URI権限の永続取得は追加しない。アンインストール/データ消去後の復元、移動した原本の探索、設定export、顔保護、24MP拡張、速度目標は対象外。
