# 試験現像の強度調整（#81）

## 目的と範囲

写真別編集の最初の縦切りとして、選択したDNGのprivate縮小試験JPEGを強度だけ変えて再生成する。
強度0〜1・既定0.5は既存仕様、表示0〜100・左右タップ1刻み・ドラッグ中の数値連続更新と指を離した画像更新は利用者の承認済み操作である。
色温度・明るさの単位や値域、編集定義の永続化、共有保存、原寸処理、操作中の軽量プレビューは対象外。

## 要件と受入条件

- FR-001: 原本照合済みのprivate結果から「強度を試す」を開く。ドラッグは連続値、左右タップは内部0.01（表示1）、範囲0〜1。数値はドラッグ中に更新し、合法なupで最後の値を現像要求に固定する。キーはup、アクセシビリティ操作は完了時に反映する。
- FR-002: ドラッグ中の各moveでqueue世代を作らない。要求ごとにrecipeと表示ticketを固定し、単一adapterでも別要求の強度が混ざらない。画像の表示強度は結果側の検証済みrecipeに基づく。旧結果・旧stage・旧操作は新状態を上書きしない。
- FR-003: 取消は編集開始時の値へ戻し、既定50は0.5へ戻して再現像する。resetは入力epochを更新する。「調整を閉じる」は最新要求と実表示が一致する場合のみ可能で、一時値を閉じた画面に保つ。永続保存ではない。写真再選択・画面再生成では既定50へ戻す。pause時は編集を取消し再確認する。
- FR-004: 原本参照・fingerprint・grantが変われば自動継承せず再選択を求める。取消された準備はIO owner内のfence・世代確保前に停止する。撮影優先、中断後の実資源解放待ち、共通coordinatorの排他を維持する。
- FR-005: 実際のprivate JPEG生成・fresh readback・原本再照合を使う。既存0.5 snapshotとの互換性と既存journal形式を保ち、正規形のprivate snapshotだけを受理する。公開用CompletedRenderには変換しない。原本と公開済み結果を書き換えない。
- FR-006: 最大1024px・顔保護なし・診断露出/暫定色・共有保存なし・一時設定であることを示す。0はRAW基準比較そのものではない。画像長押し比較は同じ原本の既存基準表示を使う。読み込み失敗・再試行・取消を操作可能にし、短い画面や大きな文字では操作欄をスクロールする。

## 検証と停止条件

単体テストで入力完了、古いtoken、取消/reset/再選択、snapshot互換、単一adapterの要求分離、取消済みIO準備を検証する。
lint・unit・Androidテストコードのコンパイルと通常CIを確認する。実機の操作感・画質・速度やAndroid gesture実行は別途確認し、コンパイルやCIをその合格証拠にしない。
強度と結果の不一致、原本の変化、未確認の公開結果、撮影優先の破壊があれば採用しない。
