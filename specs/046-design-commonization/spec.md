# Feature Specification: デザイン共通化の第三のまとまり

**Branch**: `refactor/design-commonization` / **Created**: 2026-11-07 / **Status**: Draft
**Source**: [Issue #195](https://github.com/reitojike/cinematic-camera/issues/195)。045の第三のまとまりとして保留した整理。

## User Scenarios & Testing
### US1 同じ操作と見た目を維持する (P1)
撮影・設定・診断・ロール・現像で、既存の色と選択状態を保ったまま保守可能な表示定義を共有する。
独立検証: 同じ状態の変更前後画像を比較し、下記2点以外に差がない。クリック・読み上げ状態も維持。
- 撮影の縦横、設定のSTILL/CINE/再接続/録画、診断の各タブ、ロールの一覧/部分アクセス/該当なし、現像の表示/調整/保存確認/縮小試験を対象とする。
- 手動試験とStage Clearは白枠、試験1024pxと顔保護なしはアンバー。保存状態の読み上げ通知を維持する。
### US2 現像の細部を合わせる (P2)
比較キーにも右区切りを表示し、無効な表示/比較切替は外枠・つまみを含む全体を薄くする。
独立検証: 意図した2点の差だけがあり、比較操作は2か所とも残る。
### US3 小画面の既存の到達性を保つ (P1)
共通のスクロール判定へ移しても現在の画面ごとのしきい値と情報展開時の条件を保持する。
独立検証: 境界値・文字サイズの単体検証と小画面の操作到達。

## Requirements
- FR001 色値・寸法・描画順を変更せず表示定義を集約する。
- FR002 入力処理、無効状態、contentDescription/stateDescription/selected/liveRegionの意味を変更しない。
- FR003 意図した見た目変更は比較キー区切りと無効切替全体alpha 0.4だけ。
- FR004 スクロール条件の値を維持。設定は高さ240dp・文字サイズ非考慮を既定とする。
- FR005 旧specの完了・未検証を実際の証拠に沿って更新する。

## Success Criteria
- SC001 全指定状態の前後比較でFR003以外の差0。
- SC002 既存の操作・選択・読み上げの回帰0。
- SC003 色の直書きは共通定義以外0、未使用の対象表示関数0。

## Assumptions / Boundaries
設定の文字サイズ対応は要確認の別判断。今回は現状を変えず、判断をブロッカーにしない。
入力/保存/現像/権限/一覧取得、撮影レイアウト、新規依存、比較操作削除、保存/撮影ボタン共通化は対象外。
目盛り数値の現在値近傍化も対象外として閉じる。RAW診断・実機検証を優先する。
## 検証の段階分け
診断版と実機確認を優先する最新合意により、大きな表示state分離は今回行わない。合成fixtureで比較できる撮影共通部品・ロール・現像を先に検証し、撮影・設定・診断の全画面状態比較は実機確認に残す。SC001の全状態を満たしたとは記録せず、未検証範囲をPRへ明記する。
