# 編集・撮影目盛りの統一

Status: Draft / Branch: fix/editor-capture-ruler-parity
既存関連Issue: #175 / #186。今回の追加範囲の公開は未実施。

## 要件
- spec042/044の「見た目だけ」「全範囲5ラベル維持」を今回の依頼により置換する。編集も中央選択・近傍値・両端矢印に揃える。
- 撮影と同じく左ドラッグで増加、右で減少する。1段の距離は24dp。左右タップは1段のみで絶対位置へジャンプしない。
- 強さは0〜100の整数値で入力する。内部の0〜1表現は維持し、表示だけを丸める対応にはしない。
- 基準値は強さ50、色温度0、明るさ0。ドラッグで通過すると基準値へ一旦止まり、追加8dp相当の移動で離れる。到達時にクリックの触覚を一度出し、離脱後の再到達では再度出す。OS・Viewの触覚設定に従う。
- 相対色温度・明るさの連続値、1段タップ、キー、アクセシビリティ、RESET、取消、離して反映、写真/パラメーター/セッション切替の入力無効化を維持。
- 保存・RAW・永続化ownerは変更しない。実機評価と合成試験を区別する。

## 受入条件
左右ドラッグの方向、近傍値と端点、強さの整数入力と微小移動蓄積、基準値停止と離脱/再進入、取消と支援技術を回帰検証する。
