# 写真別編集の操作部品とdraft状態

関連: [#81](https://github.com/reitojike/cinematic-camera/issues/81)。#81全体のうち、利用者が指定した操作と、写真別draftの純粋状態だけを扱う。

## 確定した操作と受入条件

- FR-001: ドラッグ中は連続的に値を変更する。タップ刻みへ量子化せず、指離し前も変更を通知する。
- FR-002: バー上のthumbより左/右をタップすると、現在値から外部指定の1段だけ減らす/増やす。タップ位置の値へ飛ばさない。thumb自体のタップは変更せず、端点を越えない。
- FR-003: 強度の値域は0〜1、reset既定値は0.5とする。強度のタップ刻み、色温度/明るさの値域・刻み・単位は呼出側から明示的に受け取り、製品既定値をこの実装で選ばない。
- FR-004: 1原本の確定済み値・draft・明示defaultsを分離する。項目間で値を保持する。resetはdraftだけをdefaultsへ、取消は開始時の確定値へ戻してsessionを終了する。
- FR-005: reset/取消/別写真/再openの古い操作を拒否する。値を変えて戻した場合も古いpreviewを最新と扱わない。表示revisionを永続queueのgenerationと混同しない。
- FR-006: 縦scroll・イベント消費・多指・操作無効化・interaction key変更で操作を中断し、後のupをタップへ変換しない。キーボード左右と読み上げの1段変更を用意する。

## 未決定・対象外

色温度の相対/絶対Kelvin、明るさの物理的な意味/範囲/刻み、強度のタップ刻み、設定確定のUIと永続化、退出時のdraft保持は後続判断。ここでの取消はprocess内sessionに限る。強度0は元画像を意味せず、既存のRAW基準比較の定義も変えない。

この部品は現行画面へ未接続。固定trial recipe、原寸diagnostic、decoder/色/顔/露出/Stage Clear演算、JPEG生成・保存・公開、撮影制御、権限・依存を変更しない。設定永続化・原本からの再書き出し・実機操作感・#81全体の完成を主張しない。

## 検証と停止条件

純粋操作/状態テストでFR-001〜006を検証し、Compose adapterのコンパイル/lintとCI・独立レビューを確認する。純粋入力テストをAndroidの実gesture配信や実機操作感の証明にはしない。未確定policyを仮の製品値にして接続する必要が出たら、その接続を止めて判断を求める。
