基準・処理・比較の限界
  • 旧固定基準はカメラWB・露出固定・profile toneなし。一般的なRAWコンバーターの標準表示の正解とは扱いません。4案は明記された共通露出補正を加えてから作っています。
  • 共通明度土台は、代表ごとに手動で決めた露出補正と有界shoulderによる比較です。DNG metadata値の自動転写でも、ProfileToneCurveを含む標準現像の完全再現でもありません。肌の局所調整と色の違いは4案側で加えています。
  • 顔・首・腕には写真別の手動領域を指定し、境界をぼかしています。髪・マイク・衣装への漏れ、境界のハロー、混色下の不自然な色は観察対象です。汎用の人物認識・自動肌検出の成功ではありません。
  • 全出力は有限範囲のsRGB表示用です。失われたRAWの色情報や白飛びを復元したという意味ではありません。ノイズ低減・美肌平滑化・顔の形の変更は行いません。
  • 等倍は画像1pxをCSS 1pxで表示します。OS拡大率・画面DPR・ブラウザ色管理・縮小補間を含む表示品質は未検証です。
  • SIGMA fp素材の結果です。Pixelの画質成立やAndroid処理の完成を示しません。原本・人物・GPSを外部へ送信する機能はありません。
