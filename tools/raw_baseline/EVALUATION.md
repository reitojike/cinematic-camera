# Stage Clearへ進む前の比較枠

この文書は評価方法だけを定める。Stage Clear・人物補正・AI・multi-frame・独自NRは未実装。

## 入力と条件

本人が許可した非公開DNGだけを使う。Pixel 9a／SIGMA fpごとに結果を分け、同じ入力hash・WB・露出基準・基準版を固定する。各cameraのnoise、WB、色matrix、RAWの処理済み度を混同しない。cameraの比較をするときも構図・ISO等の差を記録し、fpだけからPixelの成立を主張しない。

照明は002 planのS01中立光、S02赤、S03青、S04紫/マゼンタ、S05スポット/逆光、S06暗所高ISO/動体。元から飽和したchannelの完全復元を約束せず、舞台照明を肌色の均一化で消さない。写真・生metadata・私的評価メモをGit/公開Issueへ置かない。

## 同一入力の比較

| 版 | 変えるもの | 状態 |
|---|---|---|
| baseline | 固定WB/露出・LibRaw基準条件 | CLIあり。実DNG品質は素材確認後 |
| tone-only | 同じRGBへの全画面輝度カーブだけ | CLIあり。NR・肌選択なし |
| future Stage Clear | 将来承認されたlook版/強度だけ | 未実装。基準を途中で変更しない |

全体、等倍、同じ大きいcrop、SNS想定の同一縮小（例:長辺1080px）を同じ表示条件で並べる。crop/縮小は現時点では手動評価枠でありCLI生成機能ではない。中立光と色照明を別評価し、強照明の失敗を全体平均で隠さない。

## 技術品質と好みを分離

| 技術チェック（可否・理由） | 好み（1〜5＋理由、未評価可） |
|---|---|
| decode成功／色空間・WBの根拠／原本不変 | 肌の明るさ・透明感 |
| 入力飽和と現像clipの区別／highlight階調 | 照明の雰囲気・色の残り方 |
| 等倍肌・髪・衣服／noise・過剰平滑化 | 質感・立体感・粒状感 |
| banding、偽色、halo、再生成hash | 全体の印象・SNS縮小時の印象 |

未説明の色転び・clip、decode異常、原本hashの変化があれば処理工程を分離し、画作り・移植へ進まない。生成成功、受入合格、本人の好みを別々に記録する。現時点では実DNG素材なしのため、各cameraのdecode／色／noise／画質は未評価。
