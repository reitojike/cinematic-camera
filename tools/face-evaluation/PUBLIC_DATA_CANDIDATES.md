# 公開素材候補と注釈の扱い

確認日: 2026-11-15。候補調査のみ。画像の取得・端末への転送・推論はまだ行っていない。
公開されていることと、今回の評価・再配布の許諾があることは別。写真をrepoへ置かない。

## 最初の顔入り疎通に向く候補

`skimage.data.astronaut` は公式ドキュメントでNASA由来・public domainと明記される512×512の画像。
黒画像だけでなく、顔入りで座標・色・反復・3方式の結果が取れるかを確認する小さな候補とする。
1名の正面画像なので精度の優劣、ステージ照明、小顔・遮蔽の評価には使えない。
取得時には同じ版とファイルSHAを固定し、出典・変換・注釈を非公開台帳に残す。
[scikit-image公式](https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.astronaut)、
[NASAの画像利用方針](https://www.nasa.gov/nasa-brand-center/images-and-media/)。

画像の著作権条件とは別に、人物やNASAの推奨・製品の広告と受け取られる利用を避ける。
この評価で本人識別・顔認証・個人属性の推定は行わず、顔の位置のみを扱う。

## 大きなbenchmarkは今すぐ取得しない

- **WIDER FACE**: 顔検出benchmarkとしての候補だが、今回公式入口は移転先を案内し、
  移転先ページを取得できなかった。利用条件を確認済みとはしない。ミラーのライセンス表示や
  ローダーコードのライセンスを画像の許諾に流用しない。
  [公式入口](https://mmlab.ie.cuhk.edu.hk/projects/WIDERFace/)。
- **FDDB**: 公式ページの取得に失敗。条件未確認なので保留。楕円注釈を矩形へ変換するなら
  変換規則と既存矩形評価との差の明記も必要。今回は取得しない。
  [公式](https://vis-www.cs.umass.edu/fddb/)。
- **FFHQ**: 公式にデータセット・metadataはCC BY-NC-SA 4.0、個々の画像は複数の条件を
  持つと記載される。画像別の権利確認と用途の整合確認が必要で、汎用の商用可コーパスとは
  扱わない。整列・切抜き済みの顔中心で、顔なし／ステージ検出の主評価にも不向き。
  顔認証技術への利用について注意書きもあるため、安易に一括採用しない。
  [配布元README・Licenses](https://github.com/NVlabs/ffhq-dataset#licenses)。

実写精度は、最終的に本人が承認する普段の写真の条件で比較する。公開素材の成績だけで
採用を決めない。本人写真の準備・転送・実機試験は具体的な許可を得てから行う。

## 正解の注釈

疎通素材でも顔枠は人が独立に確認する。検出器自身の出力を正解にしない。
複製や回転・暗くした派生画像は同一元画像としてグループ化し、tuningとheld-outに分割しない。
同じ人物の派生画像で評価枚数が多いように見せない。

顔枠の対象範囲、半分隠れた顔、完全遮蔽、極小顔、境界で切れた顔の扱いを結果を見る前に固定。
判断不能な顔を含む画像は、ignore領域に対応していない現行集計へ投入せず別に確認する。
条件ごとのTP/FN/FPと欠測を見せ、少数の疎通画像を全般的な精度指標として公表しない。
